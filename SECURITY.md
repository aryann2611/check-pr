# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's
[private vulnerability reporting](https://github.com/aryann2611/check-pr/security/advisories/new)
instead.

Expect an acknowledgement within a few days. This is a one-person project, so
there is no formal SLA.

## Supported versions

Only the latest commit on `main` receives fixes.

## Tokens

`check-pr` only needs read access to a repository's pull requests and never
writes to GitHub. Use a token with the narrowest scope that works.
