# Contributing

Bug reports and pull requests are welcome.

1. Open an [issue](https://github.com/aryann2611/check-pr/issues) or pick an existing one.
2. Branch from `main`, make the change, and add tests when behavior changes.
3. Run `npm test` and `npm run lint`.
4. Open a pull request. Commit messages must follow
   [Conventional Commits](https://www.conventionalcommits.org/), which this
   repository checks on every pull request.

Requires Node.js 20 or newer. Run `npm ci` first.
